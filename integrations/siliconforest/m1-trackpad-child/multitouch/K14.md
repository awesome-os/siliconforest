# K14 pinch and rotation delivery

Source, host tests and native SDK only; **not installed or physically verified**.
Thunderbolt machine trials are paused by the owner. This work creates no test
slot, target workload or automatic input. Installed CIO29 keeps its old gesture
ABI until a separately authorized kernel incorporates this source.

The existing libinput1.32.0 gesture decision now enters PINCH for opposing
two-finger motion instead of discarding it. Pinned reference
`5cf833b572f5:src/evdev-mt-touchpad-gestures.c` functions
`tp_gesture_get_pinch_info`, `tp_gesture_init_pinch` and
`tp_gesture_handle_state_pinch` define distance/angle/centre behavior. Existing
per-file copyright and the MIT permission notice in NOTICE remain. No native
kernel floating-point operation was added.

Normalized physical contact separation gives scale since BEGIN (Q16,1.0=65536).
Integer CORDIC gives clockwise angle delta in hundredths of a degree; the delta
wraps to[-18000,18000]. Centre motion uses the existing pointer filter at gain100
in libinput units, before desktop pixel gain. BEGIN carries scale1 and angle0.
Updates carry current scale and incremental angle; natural scroll does not
reverse them. Pointer motion and wheel bytes stay empty during pinch.

The same100ms finger-count debounce used for scrolling/swipes freezes pinch
geometry while contact count briefly differs. Natural lift ends the pinch;
a click, substituted gesture/contact identity, controller reset or protocol
fallback cancels it. Coincident contacts below1mm cannot define rotation and
cancel rather than divide by zero. Processing runs on existing report delivery,
with no timer or polling worker.

`sf_tp_gesture_ring.h` is DESK's exact24-byte event/776-byte ring version2:
seq,phase,fingers,dx,dy,synthetic,kind,ms,scale_q16,angle_cdeg. `kind=0` is a
swipe and has scale65536; `kind=1` is pinch. Phase4 is CANCEL. The producer
uses its existing lock and sequence/ring publication. The compositor already
accepts both520-byte version1 and776-byte version2, as stated in its request.
There is no new device node or grab of a HID queue.

The root constructed-report sysctl accepts2/-2 for pinch out/in and90 for a
clockwise turn, alongside existing swipe3/4/-3/-4. Its pinch scratch storage
is heap allocated per request, freed on every exit and never changes the
physical decoder state. Events are marked synthetic; these tests have **not**
been executed on the paused M1 and cannot prove a physical gesture.

Run `sh run-host-tests.sh`. Original pointer/scroll/recorded-stroke and three/
four-finger swipe checks still pass. New tests execute the actual decoder under
ASan/UBSan, compare3601 angle vectors against independent atan2 geometry, and
check scale in/out, rotation/wrap, centre motion, brief/long finger lift,
third-finger cancellation, click/reset/basic-mode cancellation, scroll exclusion
and exact ABI offsets. Initial click cancellation tests failed: filtering both
contacts on click incorrectly produced END; the decoder now emits CANCEL for a
click/filter transition. Failed receipts remain private.

delivery, plus regression checks for scroll/swipe/click.
