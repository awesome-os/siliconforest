# SiliconForest mark

A conifer in three chevron tiers whose trunk runs on as circuit traces ending in pads.

- `siliconforest-icon.svg`: the startup-picker / volume icon (mint mark on a dark green rounded square).
- `siliconforest-boot.svg`: the boot-screen logo (off-white mark on black, no background plate).

Both are drawn on a 512 grid from the same paths; render with `rsvg-convert -w <size>`.
