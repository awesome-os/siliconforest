# Darwin public DNS/HTTP client001

This new finite userspace client advances the qualified M1 controlled TCP/UDP
link. It sends one real Darwin UDP DNS query for example.com to10.0.2.3, validates
the complete response, then sends one exact186-byte HTTP GET through a new Darwin
TCP socket to the first validated public A address. No fallback endpoint, system
resolver, default route or physical driver is enabled. HTTP/DNS are plaintext;
this is not TLS/DNSSEC server authentication.

Two sequential owned utuns provide exact point-to-point peers: DNS3 then the
selected public IP. The frozen helper verifies actual host routes, interface
metadata, baseline inventory and asynchronous teardown. No raw route ADD/DELETE
prototype is linked. A process snapshot permits only self and the exact audited
shell/init ancestor chain; the fixed foreground-only supervisor and sealed host
writer complete the fresh/exclusive guest workflow contract. This is not a
kernel-wide ownership lease against a concurrent privileged administrator.

The qualified codec remains DLNET001. The new DL27 helper keeps192-byte credit,
3s ACK deadlines, exact CRC/nonce/sequence and whitespace-only ingress. DNS phase
transition requires no partial codec frame and a host checkpoint with full ACK
credit, no queued frame and a real nonblocking relay peek. This proves that
observed boundary, not an assertion that a network can never send another packet.
Whole client/helper75s, backend90s, idle30s and close15s are explicit. Response cap
is2048. TCP_MAXSEG256 is requested/read back but is not a receive-size claim;
the actual host fixture observed931-byte payloads and retains full-MTU budgets.

Actual socket DNS/HTTP bytes and route/process/interface observations are exported
as bounded nonce-labelled hex with exact offsets/lengths. Final success requires
complete HTTP EOF/framing/content, both codec CLOSEs, exact receive accounting,
phase2 cleanup, restored tty/flags and executable rc0. Raw backend transcripts
and verified Linux recovery must independently qualify the run. The same native50
KC/libSystem9fc/input/installed m1n1 are retained. No GPU observer is included.

Host evidence: frozen DNS/HTTP codec sanitizer/equivalence checks,35 interface
fault/lifecycle tests,269 extracted actual C-parser cases/8061 assertions, exact
process-ancestry negatives,16 DL27 helper and12 typed-host tests,61 legacy tests,
and actual paced Linux DNS/HTTP+DL27 checkpoint/FIN/close with52246 ACKed bytes.
