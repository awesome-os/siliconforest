# Licence status

This file used to say that no licence had been chosen. One has been:

- The original SiliconForest code is under the **MIT License**: [`LICENSE`](LICENSE).
- Ported and adopted code keeps its own licence, as marked per file and per directory:
  [`NOTICE`](NOTICE) names every source, and [`LICENSES/`](LICENSES/) holds the licence texts.
- What is still open before a public release (per-file headers, files tagged MIT that are
  not ours to tag, the question of GPL-2.0 kernel extensions prelinked with the APSL kernel):
  [`docs/RELEASE_CHECKLIST.md`](docs/RELEASE_CHECKLIST.md).

Nothing here relicenses another project's code or states that a combined kernel collection
or system image is distributable.
